I use these libraries and components:

- Breeze icon theme
- GpgME and QGpgME — OpenPGP signing, encryption and key handling through GnuPG (optional)
- KDE Kirigami and the KDE desktop QtQuick Controls style
- KIMAP — IMAP protocol library (KDE PIM)
- KMime — MIME message parsing (KDE PIM)
- KSmtp — SMTP sending library (KDE PIM)
- OpenSSL (libcrypto) — DKIM and ARC signature verification
- Public Suffix List — publicsuffix.org, for DKIM/ARC domain alignment
- Qt 6 (Core, Gui, Network, Qml, Quick, Quick Controls 2, SQL, WebEngine, Widgets)
- QtKeychain — secure password storage (KWallet / system keyring)
- SQLite — local message and folder cache with full-text search
- Zstandard (zstd) — attachment compression and deduplication
